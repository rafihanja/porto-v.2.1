## Cara Ngecek Kualitas Website

Buat ngecek kualitas sebuah website (termasuk web porto ini), standar industri yang paling sering dipakai ada beberapa. Semuanya gratis dan gampang banget dipakainya. 

### 1. Google Lighthouse (Paling Wajib)
Ini bawaan dari browser Google Chrome. Lighthouse bakal ngasih nilai (skor 0-100) buat 4 hal penting: **Performa**, **Accessibility**, **Best Practices**, dan **SEO**.
* **Caranya:** Buka web di Chrome 👉 Klik Kanan 👉 Inspect (F12) 👉 Cari tab **"Lighthouse"** di menu atas 👉 Klik **"Analyze page load"**.

### 2. Google PageSpeed Insights (Uji Server Nyata)
Kalau Lighthouse ngetes dari komputer lokal, PageSpeed ngetes web dari server Google langsung untuk *Core Web Vitals*.
* **Caranya:** Buka web [pagespeed.web.dev](https://pagespeed.web.dev/) 👉 Masukin link web Vercel 👉 Tunggu hasil analisanya.

### 3. W3C Validator (Uji Kerapian Kode)
Ini buat ngecek apakah kode HTML dan CSS yang ditulis sudah rapi dan sesuai standar dunia atau banyak *error* tersembunyi.
* **Caranya:** Buka [validator.w3.org](https://validator.w3.org/) 👉 Masukin link web.

### 4. Responsiveness Test
Cek manual apakah web pecah kalau dibuka di berbagai ukuran layar (HP, Tablet, Monitor Ultra-wide).
* **Caranya:** Buka web di Chrome 👉 Tekan **F12** 👉 Tekan **Ctrl + Shift + M** (di Windows) 👉 Pilih resolusi layar simulasi (misal iPhone atau iPad).

---
*Dibuat menggunakan HTML, CSS, JavaScript murni dengan animasi GSAP.*
